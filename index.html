Process Notes

When I first got this assignment, none of it made sense. How can a Sharpie convey the meaning of spoken words with just a few scribbles? The answer I think might be that we do it anyway, that we forge an implied meaning, that symbols already represent meaning. This project has me imagining a world where every person had their own character system to represent written words. When it comes to cryptography, the system is only secure if the symbols can not be easily parsed or deciphered. A system that is created by one person, for one person to use is the most secure. It keeps the personal truly personal if it is employed as a cryptographic vessel.

But I feared the repetition was going to drive me crazy. But at the end, I was mellowed out and felt I made something new, that didn't exist before.
